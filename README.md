Entry for the [Dad Joke Showdown](https://make.fun/bounty/u-mfnakmal-dad-joke-showdown-1d2ce3e5) bounty on make.fun: a program that writes a single original dad joke (at most 200 characters) to `/output/entry.txt`. The joke is the whole entry.

## The joke

> I told my guitar I'd string it along forever. It said, 'That's the nicest thing anyone's ever fretted about.'

109 characters.

## Run

Requires Node 22 or later. The program writes the joke to `/output/entry.txt` (or to `$MAKEFUN_OUTPUT_DIR/entry.txt` when that is set):

```sh
node main.ts
```
